# SafeQuest — setup on a new machine

## Requirements
- Node.js 20+ (npm ships with it)

## Steps
```bash
npm install
cp .env.example .env      # then fill in GEMINI_API_KEY
npm run dev               # http://localhost:3000
```

## Other scripts
| Command | What it does |
| --- | --- |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build |
| `npm run lint` | TypeScript check (`tsc --noEmit`) |
| `npm test` | Vitest suite (ML colour/HOG tests) |
| `npm run narration` | Regenerate Sinhala narration clips into `public/audio/si` |

## What was deliberately left out
- `node_modules/` — restored by `npm install`
- `dist/` — regenerated by `npm run build`
- `.git/` — copy the original folder's `.git` too if you want the history
- `.env` — none existed; create it from `.env.example`

## Heads up
- `public/models/` and `public/ort/` (~31 MB) are required at runtime for the
  guardian avatar ML pipeline. Do not prune them.
- `public/audio/si/manifest.json` is currently empty; run `npm run narration`
  to populate the narration clips.
- Deployment notes for Azure Static Web Apps are in `DEPLOY.md`.
